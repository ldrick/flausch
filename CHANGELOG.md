# Changelog

All notable changes to Flausch. The format follows [Keep a Changelog](https://keepachangelog.com), versions
follow [Semantic Versioning](https://semver.org). This file is written by `tools/release.py`.

## [1.0.0](https://github.com/ldrick/flausch/releases/tag/v1.0.0) - 2026-11-18

### Features

- New logo, "Flausch" lettering embroidered on knit
- Embroidered app icon with cat ears
- New pink color palette and knitted app icon
- Arrange projects by hand with drag and drop
- Sort the project list
- Changelog as a list, made with love in the Black Forest
- Donate page with GitHub Sponsors and Liberapay
- About pages with the changelog instead of a dialog on start
- Swipe left or right to turn the page in the PDF view
- Filter, group and search the project list by status
- Tapping a part opens the pattern; edit parts from the project
- Parts made several times, e.g. 4 legs
- Release workflow with release PR, changelog and What's new in the app
- Project status and notes, second counter, volume keys, open PDFs from other apps
- TalkBack support, F-Droid metadata and headless UI tests
- Export and import all data as a ZIP backup
- Movable reading line in the PDF view
- Project parts with own row counters, PDF covers and new logo
- Crochet MVP with projects, row counter and PDF patterns

### Bug fixes

- Usable in landscape: pages instead of dialogs ([#24](https://github.com/ldrick/flausch/pull/24))
- Smooth page turns and double tap zoom in the pattern view
- Make the text cursor visible in dark mode
- Show the field label above a filled-in value
- Reinitialize platform state when the activity is relaunched in a live process
