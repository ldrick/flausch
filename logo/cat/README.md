# The old cat logo

The previous logo: a ball of yarn with cat ears and the yarn end curled up as the tail, kept for later use.

- `logo.svg`: line art (the app colorized it with `Theme.accent`)
- `ic_launcher_monochrome.xml`: the monochrome themed launcher icon
- `ic_launcher_yarn.png`: the launcher foreground, the ball embroidered in white chain stitch (on `ic_launcher_knit.png`)
- `icon.png`: the 512 px store icon
- `logo.py`, `knit.py`: the generators as they were in `tools/` (they write into the repo paths of that time)
