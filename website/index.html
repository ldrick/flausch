Flausch

Row counter and pattern viewer for crocheting – simple, offline, free.

/flaʊʃ/ – German for fluff: “fl”, then “ow” as in now, then “sh”.

Download for Android How to install

Features

Projects and parts

  • Split a project into parts (head, ears, body …), each with its own row counter and row goal
  • Parts made several times (e.g. 4 legs) count each piece
  • Status (planned, in progress, paused, finished) and notes
  • Continue where you left off with one tap

Patterns

  • Import PDF patterns or share them into Flausch
  • Count rows right in the pattern
  • A movable reading line marks your row on every page
  • Swipe to turn pages, zoom in with a double tap

Made for crocheting

  • Large buttons for one-handed use
  • Count with the volume keys, the screen stays on
  • Backup and restore as a ZIP file
  • Light and dark, English and German, works with TalkBack

Install

Flausch runs on Android 10 and newer. Download the APK of the latest release and open it on your phone; allow installing from your browser or file manager once.

To get updates automatically, add https://github.com/ldrick/flausch to Obtainium.

Flausch is coming to F-Droid in 2027. The F-Droid build is signed with the same key as the downloads here, so you can switch later and keep your data.

Privacy

Flausch collects no data. It requests no permissions and has no internet access, so it can't send anything anywhere. There is no account, no ads, no tracking and no analytics.

Your projects, row counters and PDF patterns are stored only in the app's directory on your device. Backups are ZIP files that you save yourself, wherever you choose. Uninstalling the app deletes its data.

This website is hosted on GitHub Pages and uses no cookies, scripts or external resources. GitHub may log technical data such as IP addresses, see the GitHub Privacy Statement.
